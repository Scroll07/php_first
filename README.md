PHP: БД, суперглобальные переменные и сессии
> **Check the DB params!**
>
> Перед отладкой PHP-проекта проверь параметры подключения к MySQL в `db.php`:
>
> - хост (`$db_host`);
> - порт (`$db_port`);
> - имя БД (`$db_name`);
> - пользователя (`$db_user`);
> - пароль (`$db_pass`).
Суперглобальные переменные
Суперглобальные переменные — встроенные массивы PHP, доступные в любом месте скрипта. Они содержат данные о текущем HTTP-запросе, введённых данных формы, сессии пользователя и окружении сервера.
`$_SERVER`
`$_SERVER` содержит техническую информацию о запросе и сервере.
```php
$_SERVER['REQUEST_METHOD']; // GET, POST, PUT и т.д.
$_SERVER['REQUEST_URI'];    // например: /login.php?from=main
$_SERVER['HTTP_HOST'];      // например: auth.local
$_SERVER['REMOTE_ADDR'];    // IP клиента; локально часто 127.0.0.1
$_SERVER['SCRIPT_NAME'];    // например: /login.php
```
Например, проверка отправки формы методом `POST`:
```php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // Обработка данных формы
}
```
`$_POST`
`$_POST` содержит данные, которые браузер отправил из HTML-формы методом `POST`.
После отправки формы PHP получает массив примерно такого вида:
```php
$_POST = [
    'username' => 'vlad',
    'email' => 'vlad@example.com',
    'password' => 'secret123',
    'confirm_password' => 'secret123'
];
```
Получение значения конкретного поля:
```php
$username = $_POST['username'] ?? '';
```
Оператор `?? ''` означает: «если ключа `username` нет, использовать пустую строку».
`$_GET`
`$_GET` содержит параметры из URL.
Например, URL:
```text
http://auth.local/login.php?message=registered
```
Тогда в PHP:
```php
$_GET['message']; // registered
```
Пример использования:
```php
if (isset($_GET['message']) && $_GET['message'] === 'registered') {
    echo 'Регистрация прошла успешно';
}
```
> Не передавай пароль и другие чувствительные данные через `$_GET`: параметры URL видны в адресной строке и могут попасть в историю браузера.
`$_SESSION`
`$_SESSION` хранит данные между разными запросами и страницами сайта. Обычные переменные PHP исчезают после завершения текущего запроса, а сессия позволяет сайту «помнить», что пользователь уже вошёл.
Перед чтением или изменением `$_SESSION` нужно вызвать:
```php
session_start();
```
В `login.php` после успешной проверки пароля:
```php
session_start();

$_SESSION['username'] = $user['username'];
$_SESSION['user_id'] = $user['id'];
```
В `index.php` защита страницы выглядит так:
```php
session_start();

if (!isset($_SESSION['username'])) {
    header('Location: login.php');
    exit;
}
```
Логика:
```text
Есть username в $_SESSION → пользователь авторизован → показываем страницу.
Нет username в $_SESSION  → пользователь не авторизован → редирект на login.php.
```
Полезные функции
`isset()`
Проверяет, существует ли переменная или ключ массива и не равно ли его значение `null`.
```php
isset($_SESSION['username']);
```
`header()`
Отправляет HTTP-заголовок. В проекте используется для перенаправления пользователя.
```php
header('Location: index.php');
exit;
```
После `header('Location: ...')` нужно ставить `exit`, чтобы остановить выполнение текущего PHP-файла.
> `header()` и `session_start()` должны находиться до любого HTML-вывода. Иначе возможна ошибка `Headers already sent`.
Полезные команды
MySQL: проверить, слушается ли порт 3306
В Windows CMD, PowerShell или консоли OSPanel:
```bat
netstat -ano | findstr :3306
```
Пример успешного результата:
```text
TCP    127.0.1.12:3306    0.0.0.0:0    LISTENING    1992
```
Это означает, что MySQL запущен и слушает подключения по адресу `127.0.1.12` на порту `3306`.
MySQL: подключиться из консоли
```bat
mysql -h 127.0.1.12 -P 3306 -u root
```
Где:
`-h` — хост MySQL;
`-P` — порт MySQL;
`-u` — имя пользователя.
